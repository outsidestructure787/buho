## Búho とは
Búho（スペイン語で「フクロウ」）は、赤ちゃんの一日をワンタップで記録するアプリです。寝た時間と起きた時間、授乳（母乳・哺乳びん・搾乳器）、おむつ、体重・体温・薬などを記録できます。夜中の 3 時に半分寝ぼけた状態でも使えるように、大きなボタン、ダークモード、片手操作で作られています。

電波がなくても使えます。記録はすぐにスマホに保存されます。二人がそれぞれのスマホで使う場合は、Google スプレッドシートにつなげば、電波があるときにスマホ同士が自動で同期します。Android、iPhone、パソコンで動き、アプリストアは不要で、無料です。

データはあなたのものです。Búho は独自のサーバーを持っていません。記録はスマホの中と、同期を有効にした場合はあなた自身の Google アカウントのスプレッドシートにだけ保存されます。

> アプリの画面は現在、英語・スペイン語・フランス語・ポルトガル語・イタリア語・ドイツ語・カタルーニャ語に対応していて、日本語はまだありません。日本語のスマホでは英語で表示されるため、以下ではアプリ内のボタン名を英語で書いています。

## 必要なもの
- **スマホ 1 台だけで使う場合：** スマホだけ。約 2 分（ステップ 1）。
- **2 台以上で使う場合：** Google アカウント（Gmail で可）と、1 回だけ約 15 分パソコン（ステップ 2）。スマホでもできますが、Google のスクリプトエディタは小さな画面では使いにくいです。
- **通院予定の表示と薬のリマインダー：** ステップ 2 に加えて Google カレンダー。さらに約 5 分（ステップ 3）。

プログラミングの知識は不要です。テキストをコピー＆ペーストして、いくつかボタンを押すだけで、それぞれ下で説明しています。

## ステップ 1. スマホにインストール
1. スマホで **https://outsidestructure787.github.io/buho/** を開きます。Android は Chrome、iPhone は Safari を使ってください。
2. ホーム画面に追加します。
   - **Android（Chrome）：** 右上の「⋮」をタップし、「アプリをインストール」または「ホーム画面に追加」を選んで確定します。
   - **iPhone（Safari）：** 下の共有ボタン（上向き矢印の付いた四角）をタップし、少し下にスクロールして「ホーム画面に追加」を選び、「追加」をタップします。
3. ブラウザを閉じ、ホーム画面のアイコン（緑の目）から Búho を開きます。今後は必ずここから開いてください。全画面の普通のアプリとして動き、電波がなくても使えます。
4. 右上の歯車（*Settings*）をタップし、*Baby details* に名前・生年月日・性別を入力します。*General* では、このスマホを使う人の名前（例：「ママ」「パパ」）を入力します。*Save* をタップします。

これで準備完了です。一人で使うだけなら、ほかには何もいりません。

## ステップ 2（任意）. 複数のスマホで記録を共有
Búho は、あなたが作る Google スプレッドシートにデータを保存します。各スマホは自分の記録をそこへ送り、ほかのスマホの記録を受け取ります。スプレッドシートとアプリをつなぐために、このリポジトリにある小さなプログラム（「スクリプト」）をスプレッドシートに貼り付けます。作業は 1 回だけです。

### 2.1 スプレッドシートを作る
パソコンで Google アカウントにログインした状態で [sheets.new](https://sheets.new) を開くと、空のスプレッドシートが開きます。左上の「無題のスプレッドシート」をクリックし、たとえば *Búho* という名前にします。

中には何も書かなくて大丈夫です。記録を保存するシートは、最初の同期のときに自動で作られます。

### 2.2 スクリプトを貼り付ける
1. 別のタブで [テキスト形式のスクリプト](https://raw.githubusercontent.com/outsidestructure787/buho/main/apps-script/Code.gs) を開きます。コードだけのページが表示されます。`Ctrl + A`（Mac は `Cmd + A`）で全部選択し、`Ctrl + C`（`Cmd + C`）でコピーします。
2. スプレッドシートに戻り、上のメニューの「拡張機能」→「Apps Script」をクリックします。新しいタブで Google のスクリプトエディタが開きます。
3. エディタには `コード.gs`（`Code.gs`）というファイルがあり、サンプルの数行（`function myFunction() { }`）が入っています。中をクリックして全選択（`Ctrl + A`）し、空になるまで削除します。
4. コピーしたコードを貼り付けます（`Ctrl + V`）。1 行目は `/**` で始まり、最後の行は閉じ波かっこ `}` です。
5. 左上の「無題のプロジェクト」は、必要なら *Búho* に変更できます。
6. フロッピーのアイコンか `Ctrl + S` で保存します。

「拡張機能」メニューに「Apps Script」がない場合は、職場や学校のアカウントで制限されている可能性があります。個人の Gmail アカウントを使ってください。

### 2.3 キーを作る
キーは、あなたたちのスマホだけが知っているパスワードのようなものです。キーがなければ、ほかの人はスプレッドシートを読むことも書くこともできません。スクリプトを更新しても消えないように、別のファイルに入れます。

1. エディタ左側の「ファイル」の横にある **+** をクリックし、「スクリプト」を選びます。`Config` と入力して Enter を押します。
2. 新しいファイルの中身を消して、[`Config.gs`](https://raw.githubusercontent.com/outsidestructure787/buho/main/apps-script/Config.gs) の内容（数行だけ）を貼り付けます。
3. `const CLAVE = 'CAMBIA-ESTA-CLAVE';` という行を探し、`CAMBIA-ESTA-CLAVE` の部分だけを、自分で考えた長いキーに置き換えます。いちばん簡単なのは、ランダムな英単語を 4 つつなげる方法です（例：`panda-monday-toast-cloud`）。引用符とセミコロンは消さないでください。
4. 保存します（`Ctrl + S`）。左側に `コード.gs` と `Config.gs` の 2 つのファイルが見えれば OK です。

キーはどこかにメモしておいてください。スマホで使います。

### 2.4 スクリプトを公開する
公開すると、スクリプトにスマホからデータを送るためのウェブアドレスが付きます。

1. 右上の青い「デプロイ」ボタンをクリックし、「新しいデプロイ」を選びます。
2. 「種類の選択」の横にある歯車アイコンをクリックし、「ウェブアプリ」を選びます。
3. 次のように入力します。
   - 「説明」：何でも OK（例：「Búho」）。
   - 「次のユーザーとして実行」：**自分**（あなたのメールアドレスが表示されます）。
   - 「アクセスできるユーザー」：**全員**。スマホが Google にログインしなくても接続できるようにするためです。ほかの人が入れないようにしているのは、前のステップのキーです。
4. 「デプロイ」をクリックすると、Google が権限を求めてきます。
   1. 「アクセスを承認」をクリックし、自分のアカウントを選びます。
   2. 「Google はこのアプリを確認していません」という画面が出ます。これは正常です。スクリプトは自分で貼り付けたもので、Google の審査を通っていないためです。「詳細」をクリックし、「Búho（安全ではないページ）に移動」をクリックします。
   3. 権限（スプレッドシートとカレンダーの表示・編集）を確認し、「許可」をクリックします。スクリプトはあなたのアカウントで動き、Búho に必要なこと（このスプレッドシートへの記録の保存と、有効にした場合のカレンダーの予定の読み取り・作成）だけを行います。
5. 「ウェブアプリの URL」が表示されます。`https://script.google.com/macros/s/` で始まり `/exec` で終わる長いアドレスです。「コピー」をクリックして保管し、「完了」をクリックします。

アドレスとキーは、自分宛てにメールやチャットで送っておくとスマホで貼り付けやすくなります。

### 2.5 1 台目のスマホをつなぐ
1. Búho で歯車をタップし、*General* を開きます。
2. *Sync with Google Sheets* の最初の欄にアドレスを貼り付け、*Access key* にキーを入力します。
3. *Save and test connection* をタップします。うまくいけば "Connection OK" と表示され、上のタイトルの横に "Synced" と出ます。

パソコンでスプレッドシートを見ると、これまでの記録が入った新しいシートができています。

### 2.6 ほかのスマホをつなぐ
すでにつながっているスマホで *Settings → General* を開き、*Share setup with another phone* をタップします。LINE、WhatsApp、メールなどでリンクを相手に送ってください。リンクにはアドレスとキーが含まれるので、記録する人以外には送らないでください。

- **相手が Android の場合：** Búho をインストール（ステップ 1）してからリンクを開くと、自動でつながります。
- **相手が iPhone の場合：** Búho をインストール（ステップ 1）し、リンクをコピーして *Settings → General* の *…or paste a setup link here* 欄に貼り付け、*Save and test connection* をタップします。iPhone では、インストールしたアプリと Safari がデータを共有しないため、この方法が必要です。

各自 *Who uses this phone?* に名前を入れておくと、記録ごとに誰が書いたかがわかります。

### スプレッドシートの見え方
記録は 1 件ずつ `eventos` シートの 1 行になります。日付、開始・終了時刻、時間（睡眠と母乳の授乳）、種類、詳細、メモ、記録した人。普通のスプレッドシートと同じように、フィルタや並べ替え、グラフ作成ができます。右端の灰色の列はアプリが使うので、手で変更しないでください。アプリで記録を削除しても行は消えず、*borrado*（削除済み）列に印が付きます。

## ステップ 3（任意）. カレンダーの予定と薬のリマインダー
同期が動いていれば、Búho は Google カレンダーから今後の予定（小児科、助産師、予防接種など）を表示したり、新しい予定を追加したり、次の服薬時刻にアラーム付きの予定を作ったりできます。

1. **カレンダーを選ぶ。** メインのカレンダーでも、赤ちゃん専用の共有カレンダーでもかまいません（二人で使うなら共有カレンダーが便利です）。作り方：[Google カレンダー](https://calendar.google.com) の左側「他のカレンダー」の横の **+** →「新しいカレンダーを作成」。二人で見る場合は相手と共有します。
2. **カレンダー ID をコピーする**（メインのカレンダーなら不要）。Google カレンダーでそのカレンダーにカーソルを合わせ、三つの点 →「設定と共有」を開き、「カレンダーの統合」までスクロールします。「カレンダー ID」は `@group.calendar.google.com` で終わる長い文字列です。
3. **Búho で有効にする：** *Settings → Calendar*。
   - *Show upcoming appointments from Google Calendar* にチェックを入れます。
   - *Calendar* は、メインのカレンダーなら `primary` のまま、それ以外なら ID を貼り付けます。
   - *Only show events containing* を使うと、個人的な予定を表示しないようにできます（例：`小児科, 予防接種, 健診`）。空欄ならすべての予定を表示します。
   - *Save* をタップすると、メイン画面に *Upcoming appointments* カードが表示されます。タップすると一覧を見たり予定を追加したりできます。
4. **薬のリマインダー：** *Settings → Medication* で薬（名前、量、何時間おきか、必要なら何日間か）を追加し、*Show medication on the main screen* をオンにして、*Create a Google Calendar reminder for the next dose* にチェックを入れます。*Given* をタップするたびに、次の服薬時刻に「💊 薬の名前」というアラーム付きの予定がカレンダーに作られます。通知を鳴らすには、スマホの Google カレンダーアプリでそのカレンダーの通知をオンにしてください。

スクリプトは、スプレッドシートの持ち主の Google アカウントでカレンダーを読みます。ほかの人のカレンダーを使う場合は、そのアカウントと共有しておく必要があります。バージョン 0.3.0 より前に同期を設定した場合は、まずスクリプトを更新し（下記参照）、エディタ上部の関数リストで `autorizar` を選んで「実行」をクリックし、カレンダーの権限を許可してから、新しいバージョンを公開してください。

## うまくいかないとき
- **"The key does not match the sheet."** スマホに入力したキーが `Config.gs` と完全には一致していません。大文字・小文字や余分なスペースも区別されます。
- **"Could not connect."** 電波がないか、アドレスのコピーが間違っています。アドレスは `/exec` で終わる必要があります。
- **"Update the Google script to use the calendar."** アプリはカレンダーを求めていますが、公開中のスクリプトが古いバージョンです。下の「Google スクリプトを更新する」を見てください。
- **"Falta autorizar el calendario"**（スクリプトからのスペイン語のメッセージで、カレンダーが未承認という意味）。エディタの関数リストで `autorizar` を選び、「実行」して許可してから、新しいバージョンを公開します。
- **"No encuentro el calendario"**（同じくスクリプトから：カレンダーが見つからない）。ID のコピーが間違っているか、スプレッドシートの持ち主のアカウントとカレンダーが共有されていません。
- **アプリが更新されない。** ネットにつながった状態で開き、数秒待つと自動で再読み込みされます。されない場合は、アプリを完全に閉じて（最近使ったアプリから消して）開き直してください。Settings の一番下、バージョン番号の横の *Check for updates* でも確認できます。
- **iPhone で設定リンクがアプリではなく Safari で開く。** 正常です。リンクをコピーして、インストールしたアプリの *Settings → General* に貼り付けてください。

## Google スクリプトを更新する
アプリは自動で更新されますが、スプレッドシートのスクリプトは更新されません。新しいバージョンの[変更履歴](../../commits/main)で必要と書かれているときや、アプリが知らせたときだけ行ってください。

1. スプレッドシートで「拡張機能」→「Apps Script」。
2. `コード.gs` を開いて中身をすべて消し、新しい [`Code.gs`](https://raw.githubusercontent.com/outsidestructure787/buho/main/apps-script/Code.gs) を貼り付けて保存します。`Config.gs` には触らないでください。キーが入っています。
3. 「デプロイ」→「デプロイを管理」。鉛筆アイコンをクリックし、「バージョン」で「新バージョン」を選んで「デプロイ」をクリックします。

`/exec` のアドレスは変わらないので、スマホ側の設定はそのままで大丈夫です。新しいバージョンで列が増える場合は、次の同期で自動的に追加されます。

## よくある質問
**電波がないときは？** いつもどおり記録できます。画面上部に未送信の件数が表示され、電波が戻ると自動で送信されます。

**二人が同時にオフラインで記録したら？** 電波が戻ると、二人の記録がまとめられます。同じ記録を二人が編集した場合は、最後の編集が残ります。

**安全ですか？** スプレッドシートは非公開で、あなたの Google アカウントにあります。スクリプトは正しいキーを受け取ったときだけ応答します。設定リンク（またはアドレスとキー）を持っている人は記録を読み書きでき、フィルタを通ったカレンダーの予定も見られるので、記録する人とだけ共有してください。

**データはどこに保存されますか？** スマホの中と、同期を有効にした場合はあなたの Google スプレッドシートです。同期せずに使っていて、ブラウザのデータを消したりスマホを替えたりすると、データは失われます。その場合は *Settings → Export CSV* で時々 CSV を書き出してください。

**お金はかかりますか？** かかりません。GitHub Pages、Google スプレッドシート、Apps Script、Google カレンダーは、この使い方なら無料です。

## 自分用のコピーを使う
自分専用のバージョンがほしい場合は、このリポジトリを fork して *Settings → Pages → Deploy from a branch → main / (root)* を有効にしてください。ビルド不要・依存関係なしの静的ファイルです（`index.html`、`i18n.js`、`sw.js`、`manifest.webmanifest`、`icons/`）。アプリを日本語化したい場合は、`i18n.js` の言語ブロックを 1 つコピーして翻訳してください。プルリクエスト歓迎です。

## このプロジェクトについて
もうすぐ父親になる私は、授乳・睡眠・おむつを記録するアプリで、わが家に合うものを探していました。電波がなくても使えること、二人が別々のスマホで使えること、データが自分たちのものであること。いくつか試しましたがどれも合わなかったので、自分用に作ることにしました。

私はプログラマーではありません。Búho は AI（[Claude](https://claude.ai)）の助けを借りて作ったので、プロの開発者の皆さんには、専門分野に踏み込んでしまうことを先にお詫びします。おかしなところや改善できるところがあれば、[issue](../../issues) を立ててください。とてもありがたいですし、きっと勉強になります。
